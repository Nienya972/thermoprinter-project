Главная Источники

Основные источники

  1. Telegram Bot API. Официальная документация для разработки бота: методы API, формат сообщений, работа с медиа. Использована при проектировании логики взаимодействия пользователя и сервиса. Дата обращения: 06.02.2026.
  2. AlexGyver: Термопринтер и печать изображений. Практический материал по подключению термопринтеров и подготовке изображений к печати. Использован для выбора подхода к аппаратной части проекта. Дата обращения: 06.02.2026.
  3. Pillow (Python Imaging Library Fork). Документация по обработке изображений в Python: изменение размера, преобразование форматов, подготовка изображения к печати. Дата обращения: 06.02.2026.
  4. pySerial Documentation. Справочник по взаимодействию с устройствами через последовательный интерфейс. Использован для настройки обмена данными с принтером. Дата обращения: 06.02.2026.
  5. Python 3 Documentation. Базовые языковые конструкции, работа с файлами и сетью, обработка исключений. Дата обращения: 06.02.2026.

Источники иллюстраций

  • Рис. 2 (термопринтер): AlexGyver (см. ссылку выше).

Комментарий к использованию источников

Приоритет отдавался официальной документации и профильным техническим материалам. Каждый источник использован по назначению: API и библиотеки — для программной части, практические статьи — для аппаратной интеграции и настройки печати.
